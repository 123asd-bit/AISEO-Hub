# AISEO Hub — SEO Tools & Content Platform

A responsive, static website starter project for a CSET489 SEO mini-project. It includes four browser-based content tools, an SEO checklist, learning guides, on-page metadata, basic robots.txt and sitemap.xml files, and a mobile navigation menu.

## Included features
- Blog title idea generator
- Meta description drafting helper
- Keyword idea brainstormer (not live search metrics)
- Article outline builder
- Manual on-page SEO checklist
- SEO basics, keyword research, and on-page checklist guides
- Responsive layout and internal links
- Page titles, meta descriptions, canonical placeholders, Open Graph metadata on homepage
- Starter `robots.txt` and `sitemap.xml`

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a local web server, run `python -m http.server 8000` from the project directory and visit `http://localhost:8000`.

## Before deploying
1. Replace every `https://example.com` in canonical tags, sitemap.xml, and robots.txt with your actual domain.
2. Verify all page content, accessibility, mobile layout, and links.
3. Add real team/project information and collect keyword/SERP/competitor data using the tools you actually use.
4. Configure HTTPS, DNS, backups, updates, and server security if deploying to a VPS.
5. Submit your actual sitemap through Google Search Console after deployment.
6. Update the privacy notice to reflect the actual hosting, analytics, cookies, and third-party services.
7. The generators use local JavaScript templates; they are not connected to an AI API and do not provide live keyword metrics. If integrating an AI API, call it from a secure backend and never expose secret API keys in frontend code.
