On-Page SEO Checklist

A straightforward review for a page before it goes live.

Content and intent

  • Does the page satisfy the main reason someone searched?
  • Is the main answer easy to find without unnecessary introductions?
  • Are facts, examples, and claims accurate and current?
  • Does the page offer something useful beyond repeating other pages?

Page elements

  • Write a unique, descriptive title.
  • Write a clear meta description that accurately summarizes the page.
  • Use descriptive headings and a logical content structure.
  • Use readable URLs and descriptive anchor text.
  • Add useful alt text to meaningful images; decorative images may need empty alt text.

Internal links and technical basics

  • Link to related pages where it helps readers.
  • Check for broken links and missing images.
  • Test mobile layout and keyboard accessibility.
  • Confirm HTTPS, canonical URL, indexing directives, and status code.
  • Confirm sitemap coverage for important canonical URLs.
A checklist is a starting point, not a ranking score. Use real testing and Search Console data to identify problems.
